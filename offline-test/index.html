    How to run it
    1. In Safari, Share → Add to Home Screen, then open it from the icon once while online.
    2. Turn on Airplane Mode. Swipe the app away to force-quit it.
    3. Open it from the icon again. If this page appears, the cache works.
    4. Save a note. It should show as pending. Force-quit and reopen; it should still be there.
    5. Turn Airplane Mode off and tap Sync pending (or wait). Notes turn synced.
    6. Leave the app alone for a week, then open it once more to see whether iOS kept the notes.
